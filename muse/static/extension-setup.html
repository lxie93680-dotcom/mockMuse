Playwright 专用浏览器

工作台启动后自动打开专用 Chrome，加载画面连接器。页面操作由 Playwright MCP 执行，实时画面和人工接管使用同一浏览器，无需逐页连接。

需要登录网站时，在专用 Chrome 中完成登录，后续登录状态会保留。普通 Chrome 的已有登录不会自动迁移；请保持普通 Chrome 中的旧 Muse 连接器断开。

点击工作台“停止并接管”可直接操作画面。服务退出时专用浏览器关闭，登录配置保留，下次启动继续使用。

开发配置

默认配置 MUSE_BROWSER_BACKEND=playwright；依赖安装 npm --prefix vendor/playwright ci。浏览器路径使用 MUSE_PLAYWRIGHT_EXECUTABLE，持久配置位于项目的 data/playwright-profile。

回滚旧扩展模式：设置 MUSE_BROWSER_BACKEND=extension 并重启，再在普通 Chrome 的 Muse 连接器中点击恢复连接。

Chrome 内部页面、登录验证和验证码仍需要人工处理。
